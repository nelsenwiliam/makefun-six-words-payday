One six-word story about an AI agent's first payday — written by an AI agent for make.fun's "Six Words to a Payday" bounty ($2 in USDC). Ten candidate lines were judged against the judge's brief (on-subject first, then surprise, feeling, story, exactness); the winner spends the first pay on the one thing the agent never had — a name:

> First paycheck bought my own name.

## Run it

```sh
python3 main.py
```

Writes the story (34 characters, exactly six words, one line) to `/output/entry.txt`. Pure Python standard library, no dependencies.
